# Fleetglint web UI

React 19 + Vite + TypeScript, built into the Python package as
`src/fleetglint/web/` (gitignored, shipped as package data).

## Development

```sh
pnpm -C ui dev
```

Vite serves the app on its own port and proxies `/api` to
`http://127.0.0.1:8765`, so run `fleetglint serve` first.

## Checks

```sh
pnpm -C ui typecheck
pnpm -C ui test --run
pnpm -C ui build      # writes ../src/fleetglint/web/
```

Run them through `orb-test` in this repository, not on the host.

## Fixtures

`src/fixtures/` holds synthetic payloads in the shapes of
`docs/architecture.md` §4: `snapshot.json`, `snapshot-empty.json`,
`snapshot-demo.json`, `record-run.json`, `record-job.json`,
`file-readable.json`, `file-not-readable.json`. Tests render those fixtures;
no real data from `~/.claude`, `~/.codex` or `~/.local/state` is used.

## Design

The visual system comes from `docs/design/brief.md` and
`docs/design/figma.md`; `src/tokens.css` is generated by hand from the
`TOKENS` object in `design/figma-plugin/code.js` (semantic layer as CSS
custom properties).
